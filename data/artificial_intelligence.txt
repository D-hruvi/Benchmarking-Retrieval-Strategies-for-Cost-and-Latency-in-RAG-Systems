ARTIFICIAL INTELLIGENCE FUNDAMENTALS

Overview
Artificial Intelligence (AI) is the broad field concerned with building systems that perform tasks normally requiring human intelligence: reasoning, planning, perception, and language understanding. Machine learning is one major approach within AI, but classical AI also includes search, planning, and logic-based reasoning that do not necessarily involve learning from data.

Search Algorithms
Uninformed search algorithms explore a state space with no additional information beyond the problem definition: BFS explores level by level (guaranteed shortest path in unweighted graphs), DFS explores as deep as possible before backtracking (memory-efficient but not guaranteed shortest). Informed (heuristic) search uses a heuristic function estimating distance to the goal to guide the search more efficiently — A* search combines the actual cost so far with a heuristic estimate of remaining cost, guaranteed to find the optimal path if the heuristic never overestimates the true remaining cost (an "admissible" heuristic).

Adversarial Search
Game-playing AI (e.g., chess, tic-tac-toe) uses adversarial search, most notably the minimax algorithm, which assumes the opponent plays optimally against you and recursively evaluates game states to choose the move that maximizes your worst-case outcome. Alpha-beta pruning is an optimization of minimax that skips evaluating branches that cannot possibly influence the final decision, significantly reducing the search space without changing the result.

Knowledge Representation and Logic
Classical AI systems represent knowledge using formal logic (propositional or first-order logic) and use inference rules to derive new facts from known ones. Expert systems encode domain-specific rules (if-then production rules) and an inference engine to answer questions or make decisions within a narrow domain, an approach that dominated AI applications before statistical machine learning became practical at scale.

Planning
Automated planning generates a sequence of actions to achieve a goal from an initial state, given a set of possible actions with preconditions and effects. Classical planning assumes a fully known, deterministic environment; more advanced approaches handle uncertainty and partial observability, connecting planning to reinforcement learning when the environment's dynamics must also be learned rather than given.

Reinforcement Learning
Reinforcement learning (RL) is a distinct AI/ML paradigm where an agent learns to make decisions by interacting with an environment, receiving rewards or penalties for its actions, and learning a policy that maximizes cumulative reward over time. Unlike supervised learning, RL has no fixed labeled dataset — the agent generates its own training experience by acting in the environment, which introduces the exploration-exploitation tradeoff: the agent must balance trying new actions to discover their value (exploration) against choosing the currently best-known action (exploitation).

The Turing Test and AI Evaluation
The Turing Test proposes that a machine can be considered intelligent if a human evaluator cannot reliably distinguish its text responses from a human's in conversation. While historically influential in framing the goal of AI, it is now widely viewed as a philosophical thought experiment rather than a practical or sufficient benchmark for evaluating modern AI systems, which are instead evaluated on specific, measurable tasks.
